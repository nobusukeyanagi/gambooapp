📝 SCR-12 Gambooブログ TOP ― 主要仕様
画面ID: SCR-12  /  対応現行URL: gamboo.jp/column/  /  優先度: 2（二次開発）
主要UI要素:
  • ページヘッダー（戻る／タイトル／通知）
  • キーワード検索バー（選手名・本文対象）
  • 上部タブ: 新着 / 人気 / 特選 / ランキング
  • フィルターチップ: すべて・競輪・オート・フォロー中・お気に入り
  • ピックアップカード（サムネ大 + タイトル + 投稿者 + 統計）
  • ブログリストカード（72pxサムネ + タグ + タイトル2行 + 投稿者 + 👁💬⭐）
  • 投稿FAB（右下フローティング、タップでブログ投稿画面へ遷移）
  • ブログ投稿導線バナー（紫グラデ）
  • ランキングカード（1位〜5位、メダル配色）
  • 人気ブロガーカルーセル（横スクロール、フォローボタン付）
主な遷移:
  • ブログカード タップ → SCR-13（ブログ詳細）
  • FAB タップ → ブログ投稿画面（WebView：/member/column/entry/write/）
  • 投稿者名 タップ → ユーザープロフィール（WebView）
  • 月間賞タブ → WebView：/topics/?tid=column_monthly_award
  • 「特選一覧」リンク → WebView：/column/pickup/
アクセシビリティ: FABはaria-label="ブログを投稿する" / タップターゲット最小44px / サムネにはalt属性 / カード全体がtabindex=0
