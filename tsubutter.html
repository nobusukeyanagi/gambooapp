💬 SCR-19 ツブッター ― 主要仕様
画面ID: SCR-19  /  対応現行URL: gamboo.jp/tbutter/  /  優先度: 2（二次開発）
位置付け: リアルタイム実況・予想シェアのSNS機能。レース進行中のつぶやきがタイムライン上位に集約。
主要UI要素:
  • ページヘッダー（戻る / タイトル / LIVEインジケーター / 検索）
  • 上部タブ: フォロー中 / おすすめ / レース（レース別タイムライン） / ランキング
  • レース文脈バー（現在実況中のレースを固定表示、タップで SCR-03 / SCR-04 へ）
  • フィルターチップ: すべて / 競輪 / オート / 予想 / 実況 / 結果
  • 投稿バー（自分のアバター + プレースホルダー、タップで投稿モーダル展開）
  • LIVEバナー（現在生実況中のレースを強調、赤グラデーション + 🔴点滅）
  • 投稿カード: アバター / 氏名・ハンドル / 経過時間 / 本文（@メンション・#タグ色付け） / レース添付カード / 予想買い目チップ / 的中バッジ / 💬🔁❤️🎰応援 の4アクション
  • FAB（オレンジ、右下・52px、タップで新規つぶやき）
  • ランキングカード（人気ツブラー・1〜5位、メダル配色 + フォローボタン）
  • 的中自慢ベスト（ポスト形式で的中バッジ + 払戻金額表示）
主な遷移:
  • レース添付カード タップ → SCR-03（競輪）/ SCR-04（オート）
  • @選手名メンション タップ → 選手詳細（WebView）
  • #タグ タップ → タグ別タイムライン
  • ユーザー名 / アバター タップ → ユーザープロフィール（WebView：現行ツブッター）
  • 🎰応援 タップ → 応援ポイント送信モーダル（Gambooポイント消費）
  • FAB タップ → 新規投稿モーダル（レース紐付け・予想入力可）
  • ランキング「全員見る」 → WebView：/tbutter/ranking/
リアルタイム要件:
  • WebSocket 接続でタイムライン自動更新（新着投稿をトップに追加）
  • LIVEインジケーター: 接続中は🔴点滅 / 切断時はグレーアウト
  • プルリフレッシュ対応 / 新着n件 通知ピルを上部に表示
アクセシビリティ: LIVE点滅は `prefers-reduced-motion` で停止 / 全アクションに aria-label / 投稿本文のハッシュタグ・メンションはスクリーンリーダーで「ハッシュタグ大垣G3」等の読み上げ
